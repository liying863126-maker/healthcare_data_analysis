## Project Goal

The goal of this project is to build a reproducible health data analysis workflow using Python and SQL to clean, query, summarize, and visualize country-level COVID-19 trends.

| Stage | Tool | Output | Purpose |
|---|---|---|---|
| Data cleaning | Python/pandas | Cleaned CSV | Prepare analysis-ready data |
| SQL database | SQLite | `covid_health.db` | Simulate a database workflow |
| SQL analysis | SQL | Summary tables | Answer structured analytical questions |
| Visualization | Python | Figures | Compare trends over time |
| Interpretation | Markdown | Findings and limitations | Communicate insights clearly |
